# OfflineTask

Aplikasi manajemen tugas Android yang dapat digunakan secara offline.

## Fitur
- Melihat daftar tugas
- Menambahkan tugas
- Melihat detail tugas
- Mengedit tugas
- Menghapus tugas
- Mengubah status tugas
- Mengatur deadline dan prioritas

## Teknologi
- Kotlin
- Jetpack Compose
- Material 3
- Room Database
- ViewModel
- Navigation Compose

## Penyimpanan Data
Aplikasi menggunakan Room Database untuk menyimpan data tugas secara lokal tanpa memerlukan koneksi internet.

## Tujuan
Project ini dibuat untuk memenuhi tugas praktikum pengembangan aplikasi mobile Android.
